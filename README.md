# PLP Python Week 7 Assignment

## Assignment Files

- **my_notes.py** – Writes notes to a text file, appends a fourth note, reads the file, and counts the lines.
- **my_notes.txt** – Contains the four notes created by `my_notes.py`.
- **report_builder.py** – Reads learner scores from a CSV file, calculates the number of learners who passed and failed, and calculates the average score.
- **hubs.csv** – Contains learner names, hubs, and scores.
- **report.txt** – The generated learner report containing the total learners, pass count, fail count, and average score.
